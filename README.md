# Non-Stop Praise Calendar

ツンデレAIを褒めると予定を登録できる、HTML/CSS/JavaScriptだけの小さなカレンダーです。

## 使い方

`index.html` をブラウザで開いてください。サーバーや npm install は不要です。

`npm start` で起動する場合は、次のURLを開いてください。

```text
http://localhost:3000
```

PowerShellで `npm` がうまく動かない場合は、次を使ってください。

```powershell
npm.cmd start
```

起動中はターミナルが待機状態になります。止めるときは `Ctrl + C` を押してください。
